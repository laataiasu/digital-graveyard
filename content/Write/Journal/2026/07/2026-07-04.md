sudah 2 minggu sejak saya memulai pekerjaan baru sebagai data quality engineer di krom bank di jakarta. dalam hidup saya sering merasakan hal seperti, dimana merasa girang saat pertama memulai melakukan sesuatu, hingga berjalan beberapa lama sampai akhirnya merasa dan bertanya, "sebenarnya apa yang dalam hidup ini saya cari". saya tidak pandai bohong, tapi mungkin orang-orang sangat baik kepada saya, sehingga meskipun saya berbohong, mereka tidak pernah memperingatkan saya, dan tetap baik kepada saya. kebohongan ini, entah sampai kapan saya harus melakukannya. sulit sekali hidup tanpa kebohongan, karena apabila kebohongan dihapuskan dalam kehidupan, maka hilang pulalah kehidupan ini. karena sejatinya saya ini malas sekali untuk hidup, dan agar hidup terus berjalan, maka saya harus tetap berbohong. 

entahlah, saya selalu menilai diri saya lebih baik dari yang lain. walau mungkin saya dipekerjakan hanya sebagai SDE 1 atau entry level, tapi saya merasa berdasarkan kemampuan dan pengalaman saya, saya mampu bekerja melebihi level senior berpengalaman, apalagi di industri IT di bidang yang tidak terlalu susah, dimana dengan AI semua bisa dilakukan, saya juga merasa, entah mengapa saya perlu dipekerjakan. 

saat saya masuk, saya disambut secara baik dengan rekan kerja. Kami mendapatkan makanan siang gratis yang menurut saya secara gizi sangat lengkap. Apabila membeli sendiri, mungkin saya perlu keluar sekitar 50 ribu hingga 100 ribu. Ada snack juga di sekitar sore, bahkan saat saya masuk hingga 2 minggu ini saya sudah memakan 3 es krim haagen daz. itu es krim mahal pertama yang saya makan, dan saya tentu tidak akan membelinya dengan uang sendiri karena mungkin biaya 1 es krim sama dengan biaya makan saya selama 5 hari. baru 1 minggu pun ternyata ada jadwal dinner tim dimana saya makan AYCE di senayan city. disana saya berbincang 1 meja dengan senior dari UI juga tapi dari jurusan matematika, ada juga orang bogor ex tokopedia, ada orang jakarta mantan bukalapak yang temannya kerja sebagai software engineer di perusahaan judi online dengan gaji 120 juta per bulan di kamboja, lalu ada juga 1 lagi koko2 mantan blibli yang seniornya kebetulan saya kenal sebelumnya di traveloka karena saat saya magang senior tersebut resign dari dari traveloka dan pindah ke blibli.

selanjutnya, teman-teman saya kebanyakan 1 generasi juga dengan saya, mungkin hanya beda kurang dari 5 tahun, kecuali level senior dan manager. saat saya masuk saya juga entah kenapa melaksanakan solat lagi. saya telah mencoba untuk meniggalkan solat, tapi hari ini tujuan solat saya jelas, yaitu untuk bersosial. tanpa solat saya mungkin sulit untuk dekat dengan tim saya. banyak sekali orang bogor, kemudian tim data analytics, ada orang ITS, orang UNPAD, UNBRAW. lalu project managenya ada orang ITB dan lain sebagainya. 

entah kebohongan apa yang perlu saya ceritakan, tapi energi saya sudah habis untuk menulis. attention span saya sangat rendah sehingga malas sekali untuk melanjutkan. tapi saya akan tetap coba paksakan untuk menulis. 

entahlah saat solat itu saya termasuk bohong atau tidak. tapi nyaman sekali rasanya solat tanpa harus membaca mantra mantra yang saya tidak tahu artinya. nyaman sekali saat saya hanya harus bernapas mengikuti tempo, dan sesekali pikiran saya melayang entah kemana, tapi menurut saya tujuan saya solat itu saya mencoba untuk mendisiplinkan pikiran, bermeditasi, bahwa saya perlu mengosongkan pikiran. karena saya menghabiskan energi saya untuk memikirkan suatu hal yang tidak penting, oleh karenanya saya selalu solat. 

hingga kemudian saya mendapatkan tugas dari learning buddy saya saat onboarding, yang saat ini sedang cuti 3 hari. saya mendapatkan tugas abstrak dengan definition of done yang tidak terlalu jelas. di saat itu saya merasa harus melakukan bullshit jobs. di saat itulah saya mengingat mengapa saya sangat benci bekerja dengan orang lain. karena orang-orang itu entah kenapa suka sekali memberikan pekerjaan yang tidak ada gunanya, padahal banyak sekali hutang teknologi pada sistem kerja mereka, dan tidak ada 1 orang pun yang memberitahukan mereka akan hal itu. 

pada beberapa hari lalu, pacar saya juga ke jakarta untuk melaksanakan interview, sehingga saya menyempatkan untuk makan malam, walau energi saya sejujurnya telah habis di tempat kerja. saya benci macet jakarta, dan kegiatan tanpa planning. di satu sisi kadang saya merasa terkejut, tapi beberapa hal tanpa rencana matang itu sangat melelahkan. di situ saya juga merasa sebagai seorang pembohong. di awal, saya merasa bahwa ia hadir di hidup saya hanya untuk saya semata. tapi beginilah saya, sebagai seorang yang tidak pandai mensyukuri apa yang didapat, saya merasa bahwa apapun tidak pernah cukup bagi saya. dan saya sudah mencoba menghentikan hubungan itu, tapi pacar saya tidak peduli meskipun hal tersebut tidak akan berjalan hingga akhir, karena di pikiran saya, ia belum cukup untuk saya, tapi mungkin ia tetap berharap bahwa hubungannya bisa berlanjut. maka saya mencoba memanfaatkan nya, dan dia juga harus memanfaatkan saya. saya sudah jelaskan juga pada pacar saya, bahwa saya orangnya transaksional, bahwa secara emosional, dia melengkapi kebutuhan saya, tapi secara public relation (tentu saya membenci saya sendiri karena hal ini, tapi sebagai manusia, beginilah tabiat saya. dan entah seberapa jauh saya mencoba untuk menghilangkannya, hal itu benar-benar sulit untuk dihilangkan) ia belum bisa memenuhui kebutuhan saya tersebut, mungkin apabila ia bisa lebih bersinar, mungkin saya akan ngaku-ngaku dan bangga, tapi tidak untuk saat ini, dan entah potensinya akan seperti apa pada masa depan. 

maka inilah jalan saya sebagai seorang pembohong.
