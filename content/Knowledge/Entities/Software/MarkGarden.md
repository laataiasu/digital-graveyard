# MarkGarden

An in-house VS Code extension bringing Obsidian-grade digital gardening workflows directly into the editor:

- **Interactive Graph View**: Physics-driven global graph and focused local graph.
- **Wikilink Navigation**: Bidirectional jumping (`[[ ]]`), header anchors, and transclusion.
- **Taxonomy & Tags**: Hybrid frontmatter and hashtag indexing with explorer views.
- **Editor Tooltips**: Real-time note previews and auto-creation.

Designed specifically for pairing with [[Quartz]] and markdown-based second brains.
