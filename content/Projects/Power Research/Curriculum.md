You're building a **PowerGraph OS** -- part political intelligence, part data architecture, part investigative tooling. You’re not doing something standard -- you’re designing a **civic intelligence system** that cuts across:

- Data engineering
    
- Knowledge graph design
    
- Political economy
    
- OSINT / investigative methods
    
- Strategic intelligence
    

So the goal isn’t just “learn data science.” It’s to become a **system-level architect of socio-political computation** -- someone who understands both power and how to map it.

## 📚 Self-Study Topics You Should Master

You can learn most of this without a master’s -- here’s a breakdown of the core domains:

---

### 📦 1. **Data + Knowledge Engineering**

> Build power graphs that make sense

| Topic                               | Why                                                   |
| ----------------------------------- | ----------------------------------------------------- |
| Entity Resolution / NER             | Identify and disambiguate people, orgs, firms         |
| Ontology Design                     | Model relationships: owns, donates_to, connected_with |
| Graph Databases (Neo4j, RDF/SPARQL) | Represent and query complex connections               |
| Data Pipelines / ETL                | Pull from AHU, LHKPN, news, CSVs                      |
| RAG / Semantic Search               | Grounded Q&A with sources, avoid hallucination        |
| Data Governance                     | Trust, provenance, citations, validation              |

---

### 📡 2. **[[Open Source Intelligence|OSINT]] + Investigative Methods**

> Know how investigators and journalists trace elites

| Topic                                      | Why                                          |
| ------------------------------------------ | -------------------------------------------- |
| Corporate Shell Mapping                    | See through nominee structures               |
| Procurement Data Analysis                  | Link tenders to donor networks               |
| Cross-border Wealth Tracing                | Find offshore links via ICIJ / OpenSanctions |
| Media Network Mapping                      | Who owns the narrative?                      |
| Power Structure Mapping (LittleSis, OCCRP) | How civic tech tracks influence              |
| Metadata & Source Tracing                  | Attribution and forensic rigor               |

---

### 🧠 3. **Political Theory + Elite Sociology**
